Opcional · Supabase
☁
Para sincronizar entre dispositivos, crie um projeto Supabase, execute o SQL abaixo e informe a URL e a chave pública (anon/publishable). Nunca use a chave service_role neste site.
Status: sincronização não configurada.
SQL de configuração
Cole no SQL Editor do Supabase e execute.
create table if not exists public.moneta_backups (user_id uuid primary key references auth.users(id) on delete cascade, data jsonb not null default '{}'::jsonb, updated_at timestamptz not null default now()); alter table public.moneta_backups enable row level security; create policy "Users can read own Moneta data" on public.moneta_backups for select to authenticated using (auth.uid() = user_id); create policy "Users can insert own Moneta data" on public.moneta_backups for insert to authenticated with check (auth.uid() = user_id); create policy "Users can update own Moneta data" on public.moneta_backups for update to authenticated using (auth.uid() = user_id) with check (auth.uid() = user_id);
